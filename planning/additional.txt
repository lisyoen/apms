### 1. 프로젝트 채팅 패널 폭 조절

- 요구: 프로젝트 화면 우측 채팅 패널의 폭을 좌우 드래그로 조절할 수 있어야 한다. 조절 결과는 프로젝트별이 아니라 모든 프로젝트에 공통 적용되며, 서버가 아닌 현재 브라우저(localStorage)에 저장한다.
- 상세 가정: 패널 좌측 경계에 드래그 핸들(폭 6px, hover 시 강조). 최소 폭 320px, 최대 폭은 화면의 70%. 더블클릭 시 기본 폭으로 복원. 키 이름 `apms.chat.panel.width`.
  ▶ 전체화면 토글 상태도 브라우저에 기억할지: (a) 기억함 (b) 항상 패널로 시작 [기본 a]
  ▶ 모바일/좁은 화면(≤ 900px)에서는 드래그 대신 전체화면 고정으로 처리해도 되는지 [기본 예]

### 2. 프로젝트 문서(md) 편집 버튼 위치·동작 오류 + 편집기 요구

- 버그: "편집" 버튼이 MdViewer 툴바("공유 링크 복사", "md 다운로드")와 다른 위치에 렌더링되고, 눌러도 편집 화면으로 전환되지 않는다.
- 요구: 편집 버튼을 툴바의 같은 줄, 같은 스타일로 배치한다. 편집 시 클로드큐 md-viewer 편집기와 동일한 기능의 편집기가 열려야 한다.
- 상세 가정(클로드큐 md-viewer 편집기 기준): 에디터/미리보기 분할(토글 가능), Ctrl+S 저장, 저장 전 이탈 시 확인, 변경 없음이면 저장 비활성, 저장 후 뷰어로 복귀·목차 갱신, 저장 실패 시 내용 유지.
  ▶ 편집 대상 범위: (a) guide·next·setting 3종 모두 (b) guide만 [기본 a]. setting.md 는 시크릿 이름만 기재되므로 저장 시 서버에서 형식 검증 후 반영.
  ▶ 동시 편집 충돌 처리: (a) 마지막 저장 승리 (b) 열었을 때 버전(updated_at)이 바뀌었으면 저장 거부 후 재확인 [기본 b]
  ▶ 편집기 구현: (a) 텍스트 영역 기반 경량 편집기(의존성 추가 없음) (b) CodeMirror 도입(구문 강조·단축키) [기본 a, 1차는 경량]

### 3. 챗봇 세션 목록 + 새 채팅

- 요구: 챗봇 상단에 현재 프로젝트의 채팅 세션 목록을 표시하고 "새 채팅" 버튼을 둔다. 기존 세션을 선택하면 그 세션을 열어 대화를 이어갈 수 있어야 한다.
- 상세 가정: 상단 바에 세션 드롭다운(제목 + 마지막 메시지 시각, 최신순) + "새 채팅" 버튼. 세션 제목은 첫 사용자 메시지 앞 40자로 자동 생성하고 이름 변경 가능. 핸드오버로 닫힌 세션(handed_over)은 목록에 "종료" 표시하고 읽기 전용으로 열림. 마지막으로 열었던 세션은 브라우저에 기억(현 구현 유지).
  ▶ 목록 형태: (a) 상단 드롭다운 (b) 패널 안 좌측 접이식 목록(claude.ai 사이드바 형태) [기본 a — 패널 폭이 좁아 드롭다운 권장]
  ▶ 세션 삭제·이름 변경 기능도 이번에 포함할지 [기본 포함]
  ▶ 전역 /chat(프로젝트 없는 대화)은 (a) 유지 (b) 제거하고 프로젝트 패널로 일원화 [기본 a]

### 4. claude.ai 유사 채팅 UX — 중단, 백그라운드 처리, 완료 알림

- 요구: 요청 처리 중 중단(Stop) 가능. 처리 중 다른 세션으로 이동해 대화를 계속하면 기존 요청은 백그라운드로 계속 처리되고, 완료 시 화면 내 토스트와 브라우저 알림으로 알린다.
- 상세 가정(구조 변경 수반): 현재 /api/chat 은 동기 처리 후 단일 SSE 이벤트를 보내므로, 요청을 서버 측 작업(run)으로 분리하고 세션별 상태(processing/done/cancelled)를 둔다. 클라이언트는 세션 상태를 SSE 또는 폴링으로 구독한다. 중단 시 LLM 요청 abort + 부분 응답은 저장하지 않음. 브라우저 알림은 최초 1회 권한 요청, 탭이 포그라운드일 때는 토스트만.
  ▶ 스트리밍 표시: (a) 이번에 토큰 단위 스트리밍(타이핑 표시)까지 포함 (b) 완료 후 일괄 표시 유지, 스트리밍은 다음 차수 [기본 a — claude.ai 유사 UX 의 핵심]
  ▶ 중단 시 부분 응답 처리: (a) 폐기 (b) 받은 만큼 저장하고 "중단됨" 표시 [기본 b — claude.ai 방식]
  ▶ 동시 처리 한도: 사용자당 동시 진행 요청 수 (a) 제한 없음 (b) 3개 [기본 b — Gemma4 단일 GPU 보호]
  ▶ 도구 호출(발주·문서 변경)이 포함된 요청을 중단하면: (a) 이미 실행된 도구 결과는 유지 (b) 도구 실행 전 단계에서만 중단 허용 [기본 a]
  ▶ 완료 알림에 클릭 시 해당 세션으로 이동 포함 [기본 포함]
