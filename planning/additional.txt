(2026-09-10 15:38 신규 — APMS 채팅/작업 화면 사용성 개선)

1. 로그인 화면에 "로그인 정보 저장" 체크박스를 추가한다.
   - 사용자가 체크하면 다음 접속 시 로그인 입력값 또는 세션 유지 흐름이 자연스럽게 이어져야 한다.
   - 보안상 저장 가능한 값의 범위와 저장 방식은 구현 전에 명확히 정리한다. 비밀번호 평문 저장은 금지하고, 기존 인증 쿠키/세션 구조와 충돌하지 않게 설계한다.

2. 채팅창 전체화면 모드에서 "패널로" 버튼을 상단 고정 위치에 둔다.
   - 현재는 채팅창이 계속 스크롤되면 "패널로" 버튼까지 같이 밀려 올라가 클릭하기 어렵다.
   - 전체화면에서도 패널 복귀 버튼은 항상 보이는 상단 영역에 고정해 즉시 돌아올 수 있어야 한다.

3. 채팅창에서 사용자가 위로 스크롤한 경우 최신 메시지로 이동하는 아래쪽 화살표 버튼을 표시한다.
   - 사용자가 최신 메시지 근처에 있으면 기존처럼 자동 스크롤한다.
   - 사용자가 과거 메시지를 읽기 위해 위로 스크롤한 상태에서는 자동으로 끌어내리지 않고, 하단 또는 우하단에 "맨 아래로/최신으로" 화살표 버튼을 보여준다.
   - 버튼 클릭 시 채팅창 맨 아래 최신 메시지로 이동한다.

4. 채팅 요청 문구 복사 버튼과 세션별 응답 복사 버튼을 추가한다.
   - 사용자가 입력한 요청 문구는 메시지 단위로 복사할 수 있어야 한다.
   - 각 세션/에이전트 응답도 개별 복사 버튼으로 바로 복사할 수 있어야 한다.
   - Markdown/코드블록이 포함된 응답은 화면 표시용 텍스트가 아니라 원문에 가까운 복사 결과가 나오도록 한다.

5. 작업 메뉴 표시 방식을 클로드큐 스타일로 재구성한다.
   - 현재 작업 메뉴가 대기, 진행, 완료 등이 탭으로 나뉘어 있어 한눈에 전체 상태를 보기 어렵다.
   - 탭 대신 위에서부터 "진행 → 대기 → 완료 → 실패 → 리포트" 순서의 섹션형 목록으로 표시한다.
   - "진행" 섹션은 현재 진행 중인 작업을 우선 전체 확인할 수 있게 둔다.
   - 진행을 제외한 "대기/완료/실패/리포트" 섹션은 각 섹션별로 기본 5개까지만 보이고, 섹션 내부에서 페이징으로 더 볼 수 있게 한다.
   - 각 섹션은 한 화면에서 상태를 훑어볼 수 있도록 접힘/펼침, 개수 배지, 빈 상태 표시를 함께 검토한다.
