우선순위 높음:

1. 작업 섹션 하단의 "새 작업지시서" 작성 섹션을 제거한다.
   - 작업 목록 하단에 상시 노출되는 작성 섹션은 화면을 길게 만들고 상태 확인을 방해한다.
   - 대신 "새 작업" 버튼을 누르면 작업지시서 작성 폼이 팝업/모달로 열리게 수정한다.
   - 모달에는 제목, 작업지시서 본문, pre-task/next-task, timeout 등 기존 작성 기능에 필요한 필드를 유지한다.
   - 저장/생성 성공 후에는 모달을 닫고 해당 작업 섹션을 갱신한다.

2. 챗봇을 펼쳤을 때 화면 폭을 넘어가 좌우 스크롤이 생기는 레이아웃 버그를 수정한다.
   - 전체화면/패널 전환 후에도 채팅 영역은 viewport 폭 안에 고정돼야 한다.
   - 긴 코드블록, 긴 URL, 긴 단어가 있어도 페이지 전체에 horizontal scroll이 생기지 않게 한다.
   - 필요한 경우 메시지 내부에서만 wrap 또는 내부 스크롤을 적용한다.

3. `test2.guide.md` 파일 수정 후 저장 시 "다른 곳에서 문서가 수정되어 저장할 수 없다"는 충돌 오류가 뜨는 문제를 버그로 보고 수정한다.
   - 사용자가 방금 연 문서를 수정해 저장했는데 외부 수정이 없었다면 저장돼야 한다.
   - revision/updated_at/If-Match 처리, WYSIWYG 변환 후 저장 전후 revision 갱신, 문서 로딩 직후 ETag 보관 로직을 확인한다.
   - 실제 재현 케이스는 `test2.guide.md` 편집 → 저장이며, false-positive 충돌을 제거한다.

4. md viewer를 스크롤하면 맨 왼쪽 사이드바가 같이 스크롤되는 버그를 수정한다.
   - 문서 본문 스크롤과 좌측 프로젝트/파일 사이드바 스크롤을 분리한다.
   - 사이드바는 viewport 안에서 고정 또는 독립 스크롤되어야 하고, 본문을 아래로 내려도 같이 밀려 내려가면 안 된다.

5. 프로젝트 설정 파일 `.setting.md`가 제목만 있고 비어 있는 문제를 수정한다.
   - 프로젝트 생성 시 기본 설정값이 들어간 `.setting.md`를 생성해야 한다.
   - 클로드큐 프로젝트 설정 파일의 기본 항목을 참고하되, APMS 공개 저장소에 들어가도 되는 일반 설정값만 사용한다.
   - 최소 포함 후보: 프로젝트 목적/운영 방식, 작업지시서 작성 기준, 워커 실행 기준, 보고서 위치/형식, 금지 사항, 공개 저장소 주의사항.
   - 기존 프로젝트의 비어 있는 `.setting.md`를 마이그레이션/보정할 방법도 함께 검토한다.
