# Dirigo 설계 문서

Dirigo 설계 문서의 원본 언어는 영문입니다. 국문 번역은 이 디렉터리에 같은 파일명과 절 구조로 함께 관리합니다. 영문 문서 목록은 [상위 README](../README.md)를 참조하세요.

각 2단계 설계 절에는 현재 저장소 구현을 기준으로 `Implementation status: implemented|partial|planned`를 표시합니다. `partial`은 문서 계약의 주요 부분 중 하나 이상이 아직 구현되지 않았다는 뜻입니다.
